# Kyle's Study Site

Interactive study pages, served by GitHub Pages at www.kyle-klugewicz.com/Foundational-EE/. Three tabs share one top bar:

- **Home** (`index.html`): how electrical engineering works as a field. The energy vs information split, the abstraction stack, the ten concentrations, the IC design abstraction levels and the chip value chain, the industries and who works where, roles, and how to get in.
- **Electrical Eng.** (`ee/`): Foundational EE. Thirteen levels from fields and Maxwell's equations to antennas, each building only on the levels before it, with Core / Build / Context tiers, worked-example dropdowns with diagrams, and 18 live labs.
- **Neuroscience** (`neuroscience/`): a twelve-level ladder from the neuron to language, with interactive models (Hodgkin–Huxley neuron, brain map, cortical layers, dopamine learning, grid and place cells).

Every page is a single static HTML file with no build step. Old links to `/#L7` style EE anchors are forwarded to `ee/`.
