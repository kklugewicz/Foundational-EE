# Foundational EE

An interactive electrical engineering study page, built from my course notes. Thirteen levels run from fields and Maxwell's equations to antennas, each building only on the levels before it.

- **Core / Build / Context** tiers show what to learn first.
- **Examples** dropdowns give worked problems with real numbers and a diagram for each.
- **18 live labs**: voltage divider loading, Thévenin power sweep, RC/RL transients, phasors, RLC resonance, convolution, pole stability, aliasing, filter families, MOSFET curves, op-amp bench, logic, shift register, wafer patterning, distributions, CLT and a link budget.
- **Fixed** and **Added** badges mark corrections to the original notes and topics that were missing.

It is a single static `index.html` with no build step, served by GitHub Pages.
